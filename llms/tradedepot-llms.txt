# TradeDepot

> TradeDepot is a Lagos-based B2B commerce and distribution platform connecting consumer-goods brands with retailers across Africa. Its ShopTopUp platform lets neighborhood retailers order inventory, and its agent "Shop Checkout" SDKs embed checkout into partner mobile apps. TradeDepot publishes no public developer portal or REST API documentation; its public developer surface is a set of mobile checkout SDKs on GitHub.

This file was generated by API Evangelist from the artifacts collected in the
api-evangelist/tradedepot repository (no provider-published llms.txt was found;

## Company

- [TradeDepot Website](https://www.tradedepot.co/): Company homepage (JavaScript single-page app)
- [ShopTopUp](https://shoptopup.com/): Retail ordering platform for neighborhood stores
- [TradeDepot on GitHub](https://github.com/tradedepot): 70 public repositories, mostly Flutter/React Native plugin forks plus first-party checkout SDKs

## SDKs

- [cordova-plugin-shop-checkout on npm](https://www.npmjs.com/package/cordova-plugin-shop-checkout): Cordova plugin for TradeDepot Shop Checkout Point (v0.1.3)
- [react-native-shop-checkout](https://github.com/tradedepot/react-native-shop-checkout): React Native wrapper for the ShopTopUp agent checkout SDK
- [agent-checkout-sdk-android](https://github.com/tradedepot/agent-checkout-sdk-android): ShopTopUp Agent Checkout Point for Android (Bintray distribution now defunct)
- [cordova-agent-checkout](https://github.com/tradedepot/cordova-agent-checkout): Cordova plugin for the ShopTopUp agent checkout
